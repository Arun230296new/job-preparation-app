Interview Practice

Search and practise these starter questions.

What is CI/CD?

CI/CD automates code integration, testing, building and delivery or deployment.

What is Docker?

Docker packages an application and its dependencies into a container.

What is Kubernetes?

Kubernetes orchestrates containers, including deployment, scaling and recovery.

What is Terraform?

Terraform is an infrastructure-as-code tool used to provision and manage infrastructure.

What is GitOps?

GitOps uses Git as the source of truth for declarative infrastructure and application deployment.
